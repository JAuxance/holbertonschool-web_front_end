# holbertonschool-web_front_end

Projets de la spécialité Front-End de Holberton School : fondamentaux du
développement web et introduction au typage en Python.

## Contenu

| Dossier | Sujet | Description |
|---------|-------|-------------|
| `html_advanced/` | HTML avancé | Structuration sémantique d'une page web, de la maquette au document complet (en-tête, navigation, sections, articles, pied de page). |
| `CSS_advanced/` | CSS avancé | Mise en forme progressive de la page HTML : variables, typographie, grille, composants et responsive. |
| `javascript-warm_up/` | JavaScript | Premiers exercices de prise en main du langage. |
| `python_variable_annotations/` | Python | Annotations de type sur les variables, paramètres et valeurs de retour. |

## Prérequis

- Un navigateur web moderne pour les pages HTML/CSS.
- Node.js pour exécuter les scripts JavaScript (`node fichier.js`).
- Python 3 pour les scripts d'annotations de type (`python3 fichier.py`).
